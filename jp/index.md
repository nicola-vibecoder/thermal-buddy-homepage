# Thermal Buddy サポートへようこそ

Thermal Buddy は、精密な温度記録と分析のために設計されたネイティブ iOS アプリケーションです。産業機器の追跡、屋外状況の監視、または個人のプロジェクトなど、温度データを記録し理解するために必要なツールを提供します。
