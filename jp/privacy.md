# プライバシーポリシー

**最終更新日: 2026年4月26日**

Thermal Buddy（以下「当アプリ」）は、お客様のプライバシーを保護することに全力を尽くしています。このプライバシーポリシーでは、データの取り扱いについて説明します。

## 1. データの収集と利用

Thermal Buddy は、データをデバイス内にローカルに保存し、プライバシーを保つように設計されています。

### ユーザー生成データ
当アプリでは、以下の種類のデータを作成・管理できます。
- **アクティビティ・タイプ (Activity Types)**: 温度記録アクティビティのカスタムラベル。
- **ギア・カテゴリー (Gear Categories)**: 監視対象の機器やアイテムの分類。
- **シーンのカスタマイズ (Scene Customization)**: 記録環境ごとのパーソナライズされた設定と説明。

これらのデータはデバイス内に保存され、有効にしている場合は、お客様個人の iCloud アカウントを介して同期されます。開発者がこれらのデータにアクセスすることはありません。

### アナリティクスとクラッシュレポート
Thermal Buddy は、アナリティクスデータ、クラッシュレポート、その他のテレメトリデータを一切収集しません。ご利用状況に関するデータが開発者に送信されることはありません。

## 2. 人工知能 (AI) の利用

Thermal Buddy では、お客様の個人データを処理する**生成AIや自動意思決定プロセスは使用していません**。データの整理や記録はすべて、ユーザーの直接入力に基づいて行われます。

## 3. サードパーティサービス

- **iCloud**: iCloud 同期を使用する場合、データは Apple のプライバシーポリシーに従って Apple のサーバーに保存されます。
- **GitHub**: GitHub を通じてバグ報告を送信する場合、提供された情報は GitHub プラットフォーム上で公開されます。

## 4. データの保持と削除

- **保持**: お客様のデータは、アプリがインストールされている間、または iCloud バックアップを維持している間、デバイスと個人の iCloud ストレージに保存されます。開発者が独自のサーバーにデータを保存することはありません。
- **削除**: お客様はいつでも以下の方法でデータを削除できます。
    1. アプリ内で個別のログを削除する。
    2. デバイスからアプリを削除する。
    3. iOS の iCloud 設定からアプリのデータを管理・削除する（設定 > Apple アカウント > iCloud > アカウントのストレージを管理）。

## 5. コンプライアンス

このポリシーは、データの透明性とユーザープライバシーに関する 2026年度 App Store レビューガイドラインに準拠するように設計されています。

## 6. お問い合わせ

このプライバシーポリシーに関するご質問は、GitHub の Issues ページからお問い合わせください。
